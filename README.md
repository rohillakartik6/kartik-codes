# Kartik Rohilla — Portfolio

Personal portfolio for **Kartik Rohilla** (Kartik Codes): software engineer focused on React.js and .NET.

## Stack

- React 18 (Create React App)
- Netlify (SPA redirects + Forms for contact)

## Scripts

```bash
npm install
npm start      # http://localhost:3000
npm test
npm run build
```
